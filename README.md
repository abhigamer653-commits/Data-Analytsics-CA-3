# Titanic Survival Prediction Using Random Forest

## 1. Project Overview
This project predicts whether a passenger survived the Titanic disaster using Machine Learning. The Random Forest Classification algorithm is used to train the model and make predictions based on passenger details.

## 2. Objective
The main objective is to analyze the Titanic dataset and build a Machine Learning model that predicts passenger survival.

## 3. Dataset
- **Dataset:** Titanic Dataset
- **Source:** Kaggle
- **File Used:** `train.csv`
- **Target Column:** `Survived`

The dataset contains passenger information such as:
- Passenger ID
- Passenger Class
- Name
- Gender
- Age
- Number of Siblings/Spouses
- Number of Parents/Children
- Ticket Fare
- Embarked Location

## 4. Algorithm Used
**Random Forest Classifier**

Random Forest is a supervised Machine Learning algorithm. It uses multiple decision trees to make predictions and combines their results to improve accuracy.

## 5. Technologies Used
- Python
- Google Colab
- Pandas

- Matplotlib
- Seaborn

## 6. Project Workflow
1. Import the required Python libraries.
2. Load the Titanic dataset.
3. Perform Exploratory Data Analysis (EDA).

## 7. Model Evaluation
The model is evaluated using the following performance metrics:

- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix
- ROC Curve

## 8. Visualizations
The project includes:
- Survival Count Plot
- Gender vs Survival
- Passenger Class vs Survival
- Age Distribution
- Confusion Matrix
- Feature Importance Graph
- ROC Curve

## 9. Result
The Random Forest Classifier learns patterns from passenger information and predicts whether a passenger survived or did not survive.

The model performance is evaluated using classification metrics and visualizations.

## 10. Conclusion
This project demonstrates how Machine Learning can be used to solve a classification problem. By using the Random Forest algorithm, we can predict Titanic passenger survival based on different passenger features.
